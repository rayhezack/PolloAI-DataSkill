### 1. 创作大盘是否包含 API 任务？

你在第 1 版只回答了支付这一半（见第二节第 1 条），创作的第 2 点是空的。

### 2. `submit_time` 为空的含义

创作任务表的 `submit_time` 为空，AI 理解为任务在提交给生成供应商之前就失败了。10/31 有 13,801 个这样的任务。「请求任务数」就是按 `submit_time` 非空来算的，所以这条理解决定请求任务数对不对。

**你的结论**（对的话写 ✓）：

`submit_time`为空总共有三种含义：

1. 没发到厂商的失败任务：被风控、内容审核拦下，或者扣费失败、素材上传失败，厂商没受理，所以没有提交时间。11-24 有 1.3 万个，占为空的绝大部分，其中 95% 是风控和审核。 

2. 语音转写：它不产出作品，而 submit_time 是从作品表取的，所以一直是空的，但其实已经发给厂商了。10-27 开始有，11-05 起每天几百个。 
3. 导演模式导出：走我们自己的渲染服务，不经过模型厂商，每天一百多个。



### 3. 创作用户数以哪张表为准

用户活跃日表里也有「创作用户数」和「创作留存」字段，和创作任务表自己算的结果差 0.1%–0.3%。例如 10/31 创作用户：活跃日表 28,837，任务表 28,827。

- **AI 建议**：创作类指标一律以创作任务表为准，活跃日表的创作字段只做快速参考。理由是你在 R0 C4 定过「创作全链路唯一来源是任务表」。

**你的结论**（同意写 ✓）： ✓

### 1. 支付大盘包含 API ⚠️ 改动了 R0 的锁定结论

> 你的原话：「支付大盘应该统计所有的付费类，包括 API。只有分析侧，比如分析支付转化漏斗（主动付费漏斗和自动续订漏斗），才会剔除 API。」

R0 B-08 当时锁的是「支付GMV、实收GMV 都排除 API」，这次按你的最新说法改了。2026-10 的数字变化如下：

| 指标 | 原（不含 API） | 现（含 API） |
|---|---|---|
| 支付GMV | $4,079,094 | **$4,108,794** |
| 实收GMV | $3,970,775 | **$3,995,232** |
| 订单数 | 90,540 | **90,719** |
| 支付用户数 | 52,104 | **52,170** |
| 退款率 | 2.66% | **2.76%** |

API 的规模是 179 单、$29,700，占 GMV 的 0.7%。付费墙漏斗和续费指标本来就不含 API，不受影响。

**落地**：支付GMV、实收GMV、退款、订单数、支付用户数、单均价、客单价、日均 GMV 都去掉了「排除 API」的条件；AI 规则 R3 改为「大盘含 API，做转化漏斗分析时剔除」。（README R3、M-PAY-001~009）

### 2. 成功率和采纳率

> 你的原话：任务成功率 = 成功任务数 / 创作任务数；任务采纳率 = 采纳任务数 / 创作成功任务数；作品成功率 = 成功产出作品数 / 产出作品数；作品采纳率 = 采纳作品数 / 成功产出作品数。

| 指标 | 2026-10 |
|---|---|
| 任务成功率 | 6,946,038 ÷ 7,896,614 = **88.0%** |
| 任务采纳率 | 2,745,317 ÷ 6,946,038 = **39.5%** |
| 作品成功率（新增） | 9,201,758 ÷ 10,641,670 = **86.5%** |
| 作品采纳率 | 3,078,159 ÷ 9,201,758 = **33.5%** |

**落地**：新增「产出作品数」（`SUM(output_cnt)`，含失败作品）和「作品成功率」。（M-CRE-011/012/013，新增 M-CRE-017/018）

### 3. 失败任务扣积分、生成成本缺失：转数仓

### 5. 采纳：不标注成熟期，另加「当天采纳」

> 你的原话（C1）：「没问题。但是需要提示数仓增加当天采纳口径。」
> 你的原话（C4）：「不用标注。增加一个当天采纳任务数即可，不需要限定任务什么时候创建成功，只要当天有采纳就统计进采纳任务数。」

AI 的理解分两点：

- **3 日采纳**：不再要求「任务创建满 3 天」，也不标注「未成熟」，直接报。
- **当天采纳任务数**：当天有采纳的任务就算，不论任务哪天创建。现在的创作任务表做不到，因为它只有按任务创建日归属的 3 日采纳字段，所以已登记为数仓待办第 3 条。

数仓加字段之前，AI 被问到「当天采纳」会说明暂无数据，不会拿 3 日采纳顶替。

**落地**：P-27、M-CRE-004/006、新增 M-CRE-019（草稿，待数仓）

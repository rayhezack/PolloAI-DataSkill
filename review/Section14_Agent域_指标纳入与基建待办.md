## 已纳入的业务结构

Agent 有两条北极星链路，共用 Agent 访问用户作为起点：

- **创作北极星：成功创作用户数（M-AGT-004）。** 拆为访问用户 → 发消息用户 → 生成发起用户 → 生成成功用户，分别对应 M-AGT-001、002、003、004 及转化率 M-AGT-005~007。
- **商业化北极星：Agent 归因 GMV（M-AGT-010）。** 拆为访问用户 → 付费墙触达 → 付费墙提交 → Agent 支付 GMV，并配套支付用户、订单、ARPPU、支付转化率和收入占比。

Agent 创作链路按用户×日统计主漏斗；会话采纳率按 session×生成日统计；订单归因按同端、同用户、同支付日、支付前最近一次订阅提交回连 Agent 曝光，不能把用户历史上曾进入 Agent 后的所有支付都算作 Agent 收入。

## 当前指标范围

[Agent 指标卡](../L2_metrics/agent.yaml)已收录 M-AGT-001~023，分为：

- 创作北极星及漏斗：访问用户、发消息用户、生成发起用户、生成成功用户及三段转化率。
- 支付北极星及漏斗：付费墙触达、付费墙提交、支付用户、支付订单、归因 GMV、触达率、支付转化率、ARPPU、收入占比。
- 质量、诊断与护栏：session 采纳率、生成失败任务、积分不足占比、生成任务时长 P90、单成功创作用户积分消耗。

当前所有 Agent 指标均为 `draft`，`table: TBD`，不作为现有取数口径。App/Web需要分端输出；`is_payer` 是分层维度，不默认过滤掉免费用户。
